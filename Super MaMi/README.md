# Super MaMi

Por ahora no hay scraper. Solo está `docs/Almacén _ Super MaMi.pdf`, una captura de la categoría
Almacén que sirve de referencia para los selectores.

Super MaMi comparte la tienda online con Dino (`dinoonline.com.ar`), así que se puede scrapear con
la configuración `dino` del scraper genérico (`_Varios supermercados/v4`).
